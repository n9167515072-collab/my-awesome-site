# Reference notes — LunaLum Deck Studio

Visual/technical references gathered during product definition. This file
is references only — qualities worth studying, and what to avoid. It does
not propose a website concept; see `concepts/` for that.

## Reference sites (visual/technical direction, not competitors)

Deliberately drawn from strong physical-product sites, not from other
Tarot brands:

- **Lusion** — https://lusion.co — a large 3D object as the page's central
  character: object reacts to cursor, camera moves, one product state
  continuously morphs into another.
- **Caeli Energie** — on-scroll product presentation — the product doesn't
  disappear after the hero; it travels with the visitor through the whole
  page, changing as they scroll.
- **0110 Studio** — 3D scroll animation — bolder spatial scenes; objects
  existing in 3D space with the camera moving between them rather than
  sitting flat on a page.
- **Plus X Digital Showroom** — a "digital exhibition" feel; each exhibited
  object gets its own small world with its own background, typography, and
  atmosphere.
- **Organimo** — product experience — surreal presentation of an ordinary
  physical object; an object becoming a door, a space, or a transition
  between sections.
- **Zero Tech by Lusion** — balance between showy realtime 3D and a
  functioning commercial site. Explicit client warning drawn from this
  reference: don't build a tech demo a visitor can't read as a clear
  commercial offer.
- **Apple (AirPods Pro page)** — realistic, disciplined execution: large
  product, sticky scenes, scale/angle changes, progressive detail reveal —
  achievable with pre-rendered sequences rather than heavy realtime 3D.
- **Boba (product slider)** — transitions between products: a central
  object stays roughly in place while artwork, environment, color, and
  type morph around it as you move between items.

## Anti-references (what to avoid)

- Printing-house sites in general.
- The standard layout: "Услуги / Преимущества / Этапы работы / Отзывы /
  Форма заявки" (services / benefits / process steps / testimonials /
  contact form) as a generic template.
- Marketplace-style product card grids.
- Typical/stereotypical esoteric design language.
- Overly complex 3D sites that turn a commercial landing page into a game
  and perform poorly on mobile.
