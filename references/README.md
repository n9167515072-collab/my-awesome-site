# references

Reference material for this project (design references, briefs, external
docs) to consult while building the site.

- `REFERENCE-NOTES.md` — reference websites and visual references only:
  what quality each one demonstrates, plus anti-references. No proposed
  website concept lives here — see `concepts/` for that, and `PRODUCT.md`
  for confirmed product facts.
- `screenshots/` — real screenshots of reference sites, used to ground
  the visual analysis instead of relying on description/memory alone.
- `REFERENCE-ANALYSIS.md` — the final, screenshot-corrected per-reference
  analysis (supersedes earlier chat-only analysis passes).
- `TASTE-PROFILE.md` — the client's visual taste, split into confirmed
  taste (A), product-specific opportunities (B), and testable concept
  hypotheses (C). Cite this, not chat history, for taste going forward.
